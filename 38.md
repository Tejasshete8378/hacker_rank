### Explaination of working enumerate() and sorted()

Using a loop with `enumerate()` and `sorted()` to take an unordered collection of names and print them in a clean, numbered sequence.

### Code

```python
unique = {'Bob', 'Alice', 'Charlie'}

for index, name in enumerate(sorted(unique), start=1):
    print(f"{index}. {name}")

```

### Output

```text
1. Alice
2. Bob
3. Charlie

```

### Explanation

1. **`sorted(unique)`**: Because Python sets are **unordered collections**, items do not have a fixed position. The `sorted()` function takes the set, sorts the elements **alphabetically** (or numerically), and returns them as a standard **sorted list** (`['Alice', 'Bob', 'Charlie']`).
2. **`enumerate(..., start=1)`**: This built-in function takes an iterable and adds a **counter** to each item. By default, it starts counting from `0`, but passing **`start=1`** tells Python to begin numbering the items from **`1`** instead.
3. **`for index, name in ...`**: In every iteration of the loop, `enumerate` **unpacks two values simultaneously**:
* `index`: The current sequence number generated (e.g., `1`, `2`, `3`).
* `name`: The actual item from the sorted list (e.g., `'Alice'`).


4. **`print(f"{index}. {name}")`**: Uses an **f-string** to cleanly combine the index number, a period, and the student's name into a readable, formatted output line.
