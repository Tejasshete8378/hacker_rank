# The Captain's Room - Problem Solution & Explanation

This repository contains a clean and efficient Python solution for **"The Captain's Room"** challenge (commonly found on platforms like HackerRank).

---

## 📌 Problem Description

Mr. Anant's multivariate hotel has an infinite number of rooms:

* **Family Rooms:** Every regular family stays in a group of the exact same size (`size`). Their room numbers appear in the list that many times.
* **The Captain:** The Captain is traveling alone, so their room number appears only **1 time** in the entire list.

**Goal:** Given the group size and the unordered list of all room numbers, find and print the Captain's unique room number.

---

## 💡 The Mathematical Logic & Why We Divide by `size - 1`

Instead of searching through every element one by one, we use a mathematical shortcut with **sets** and **sums**:

1. **Unique Set (`unique_set`):** We convert the room list into a set to remove all duplicates, leaving a single copy of each room number.


2. **Pretend Total (`unique_total`):** We take the sum of our unique set and multiply it by the group `size` (`unique_sum * size`). This creates a mathematical baseline as if *every* room (including the Captain's) appeared the full group size times.
* In this pretend total, the Captain's room is counted **`size` times**.


3. **Real List Total (`duplicate_sum`):** In the actual room list, the Captain is traveling alone, so their room is only counted **`1` time**.

4. **The Difference:** When we subtract the real room list sum from our pretend total (`unique_total - duplicate_sum`), all the regular family rooms cancel out completely to zero because they matched in both places.
* However, because the Captain's room was counted `size` times in the pretend total and only `1` time in the real list, the subtraction leaves behind extra copies of the Captain's room:
$$\text{Difference} = (\text{Captain} \times \text{size}) - (\text{Captain} \times 1)$$


$$\text{Difference} = \text{Captain} \times (\text{size} - 1)$$




5. **Dividing by `size - 1`:** Because the resulting `difference` holds the Captain's room number multiplied by `size - 1`, we must divide the difference by `size - 1` to strip away those extra copies and leave just one single Captain's room number:

```text
captains_room = difference // (size - 1)

```

---

## 💻 Python Code

```python
if __name__ == '__main__':
    size = int(input())
    room_no = list(map(int, input().split()))  # Real list
    unique_set = set(room_no)
    
    duplicate_sum = sum(room_no)
    unique_sum = sum(unique_set) 

    unique_total = unique_sum * size

    difference = unique_total - duplicate_sum

    # Divide by (size - 1) using floor division (//) to isolate the Captain's room and ensure an integer output
    captains_room = difference // (size - 1)

    print(captains_room)

```
